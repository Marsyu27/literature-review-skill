# 锚点格式与可核验性（Source Anchoring）

每条笔记、每个字段、每个知识点都要能**指回原文**。

## 锚点格式（按可用粒度）

- `page=N`：页码（从 1 起）。
- `§2.3`：章节号。
- `¶3`：段落号（章节内序号）。
- `Fig. 2` / `Table 1` / `Eq. (3)`：图表/公式编号。
- 组合示例：`§2.3 ¶3`、`page=4, Table 2`、`Fig. 2`。

## 规则

1. 锚点必须指向**真正对应**的位置，不是笼统的"见正文/见原文"。
2. 粒度与可核验性匹配：关键结论尽量到 `§+¶+图表`；次要信息到 `§` 即可。
3. 无法确定位置 → 标 `uncertain` 并写入 `uncertainties`，**不伪造锚点**。
4. 图表/公式为图片且内容不可读 → 保留编号与页码，标"内容不可读"。

## 可核验性

- 第三方依据锚点能定位到原文对应位置，核对笔记内容是否一致。
- 锚点失效（页码错、章节对不上）→ 标 `uncertain`，重新定位。

## 样例（示意）

```
"findings": "准确率 0.81 vs 0.79 (p<0.05)"
"source_anchor": "§4 Table 2"   # 指向结果表，而非"见正文"
```
