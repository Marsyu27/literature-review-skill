# 断言拆解规则（Assertion Decomposition）

把段落拆成**原子断言**，每条可独立判断真假。核心：**单一主体、单一关系、单一客体**。

## 原子性判据

一条断言 = 一个 `subject – predicate – object`：
- 只有一个主体、一个关系、一个客体。
- 拆开后每条都能独立回答"真/假/无法判断"。

## 复合句拆解

| 结构 | 拆法 | 示例 |
|---|---|---|
| 并列（and / 且 / 同时） | 拆成多条，各保留各自限定 | "A 上升且 B 下降" → 两条 |
| 因果（because / causes / 因此） | 拆出因果关系，predicate 只用词表内 `causes`；原因作主语、结果作宾语，反向表达也须调换主客，不得自造词表外的反向因果谓词 | "X 导致 Y" → (X, causes, Y)；"Y 由 X 引起" → (X, causes, Y) |
| 让步（although / 尽管） | 主句 + 让步子句各一条，保留让步关系 | "尽管 A，仍 B" → 两条 |
| 条件（if / under X / 当…时） | 条件作为断言的限定范围，不单独成断言（除非条件本身可验证） | "在 X 下 Y" → (Y, …, 限定: X) |

## 保留限定与条件

- 每条断言保留原句的**条件、范围、限定词、显著性**：如 `under X`、`n=3`、`p<0.05`、`may`、`in vitro`。
- 限定词丢失 = 断言失真，禁止。

## 粒度判据

- 过粗（多条事实塞一条）→ 继续拆。
- 过细（拆到无法对应原文最小证据）→ 合并回可核验的最小单位。
- 目标粒度：**一条断言对应一处可定位的最小证据**。

## 样例（示意）

原文：`Treatment A reduced tumor size by 30% (p<0.05) in mice, and improved survival.`
拆成：
1. `(Treatment A, reduces, tumor size)` · 限定 `by 30%, p<0.05, in mice`
2. `(Treatment A, improves, survival)` · 限定 `in mice`

> 若第 2 条原文未给数值/显著性，如实保留"未报告"。
