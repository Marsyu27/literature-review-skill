# 文献筛选与纳排

筛选是可复现的第一步：**纳排标准先于筛选写明，一致执行，留下完整记录与计数**。

## 纳排标准写法

- 由研究问题反推：对象（人群/物种/材料/体系）、干预或暴露、对照、结局指标、研究设计、时间范围、语言与文献类型（原始研究/综述/评论）。
- 每条标准写"为什么"：它服务于研究问题的哪个部分，排除哪类不相干文献。
- 标准写好后不随筛选结果临时改动；确需改动时记录改动与原因（进 `change_record`），并说明是否影响已筛条目。

示意（仅示例格式）：

| 标准 | 类型 | 理由 |
|---|---|---|
| 纳入：报告 X 与 Y 的关系且有量化结果 | 纳入 | 直接回答研究问题 |
| 排除：纯理论推导、无数据 | 排除 | 无证据可提取 |
| 排除：样本量 < 10 且无统计检验 | 排除 | 证据强度不足 |
| 仅摘要：无法获取全文 | 标记 | 只用于背景与趋势 |

## 三类情形的处理

1. **重复文献**：识别同题不同版本（同一作者同年多篇、预印本与正式版、同一数据集多次发表）。保留一条主记录（以正式版/更新版为准），其余标 `excluded_duplicate` 并注明与主记录的关系。
2. **低相关文献**：标题/摘要/全文均不满足纳入标准 → `excluded_irrelevant`，写清不满足哪条标准。
3. **仅有摘要**：标 `abstract_only`。摘要可支持背景与趋势性陈述；需要方法细节、数值、结论细节的论断不得仅凭摘要，须标"摘要未报告"。

## 筛选记录与计数（可复现）

每条文献一条记录：`{id, status, reason, evidence_location}`，并同步维护 PRISMA 式计数：

```
identified（识别总数）= duplicates_removed + screened
screened = excluded_irrelevant + excluded_other + abstract_only + included
```

- 等式必须成立（校验脚本核对）；不成立的计数比缺失更糟。
- 排除按"第一条命中的排除标准"归类，不重复计数。
- 最终纳入集合必须与研究问题对齐：能回答研究问题的才纳入。

## 边界情形

- **检索为空**：如实写为空，说明检索词与范围，不编造文献。
- **全部被排除**：写清排除理由，返回空集并说明，不强行纳入。
- **题录信息不足以判断**：标 `abstract_only` 并在 `reason` 写明"信息不足，按仅摘要处理"。
