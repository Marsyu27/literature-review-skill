# 证据提取与强度分级

对纳入文献分两层提取：先填**跨文献比较矩阵**（一篇一行，统一字段），再抽**证据行**（一条一个论断）。比较矩阵是主题归纳与冲突识别的工作底稿；证据行是草稿写作与审计的回链单元。

## 比较矩阵字段

| 字段 | 内容 |
|---|---|
| `design` | 研究设计（实验/模拟/队列/综述…） |
| `population` | 对象与样本（材料体系/人群/规模） |
| `method` | 方法要点（模型、工艺、测量手段） |
| `metrics` | 评价指标与口径 |
| `main_results` | 主要结果（含关键数值） |
| `conclusions` | 作者结论 |
| `limitations` | 局限（作者自述或显而易见者） |

填矩阵时只写原文存在的内容，缺项填「未报告」。矩阵完成后，主题、冲突、空白都从矩阵里读出来，而不是凭印象。

## 证据行字段

| 字段 | 说明 |
|---|---|
| `id` | E1、E2… 全文唯一 |
| `source_id` | 对应 `sources` 的文献 id |
| `excerpt` | 原文逐字短摘录（一两句，不转述） |
| `location` | 页码/段落/图表编号 |
| `claim` | 该摘录支撑的**单一**论断 |
| `strength` | 证据强度（见下） |
| `note` | 方法/口径/条件差异、是否二手引用 |

提取原则：

- 一条证据行只承载一个论断；一句原文支撑多个论断时拆成多行。
- 摘录必须逐字来自材料；材料没有的标「未报告」，不脑补数值或结论。
- 数值、效应量、置信区间、样本量逐字保留；跨文献比较时先统一口径（单位、指标、人群），注明换算。
- 同一主题的多篇文献，比较字段保持一致，否则无法归纳。

## 证据强度四级

| 级别 | 含义 | 措辞 |
|---|---|---|
| `proven` | 多篇一致且研究设计匹配，能支撑该论断 | 研究表明 / 已证实 / 一致表明 |
| `suggestive` | 单篇或设计局限，提示但不足以定论 | 初步表明 / 提示 / 有迹象 |
| `contested` | 存在结论相反或方法互斥的文献 | 仍有争议 / 结论不一致 |
| `not_reported` | 材料中未报告该信息 | 尚未报告 / 未见报道 |

判定看三件事：**一致性**（多篇是否同向）、**设计匹配**（方法能否回答该论断）、**样本与效度**（规模、对照、偏倚）。不因"结论有趣"上调强度，不因"与主叙事不符"下调。

## 常见错误

- 把单篇小样本结果写成 `proven`。
- 把摘要里的一句话当成全文已报告的方法细节。
- 把两篇设计不同的研究直接合并成一个数字。
- 二手引用不标注：一篇"提到"某结论的文献其实是转述他处——应标为二手并指向原始出处，或降级为 `suggestive`/`not_reported`。
