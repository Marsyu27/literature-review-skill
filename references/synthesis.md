# 综述草稿与引用

草稿建立在证据表之上：没有证据行的句子不写；每条论断能反向查到证据行。

## 写作顺序

1. 按主题定分节（对应 `themes`）。
2. 每节先写**结论句**（该主题综合出的判断），再列支撑证据；结论句的强度取支撑证据的**最低**强度，多篇弱证据凑不出强结论。
3. 一段只承载一个论点；每条论断给编号 C1、C2…，句末标注 `(作者, 年份)` 与证据行号 `(E3; E7)`。
4. 文末附**论断↔证据对照表**（claim_id → evidence_ids → 文献与位置），核验者无需通读即可抽查。

## 引用与回链

- 句末作者-年份引用，链接用材料中已有的 DOI/URL；同作者同年用 a/b 区分。
- 每条实质论断至少一条证据行，且该证据行的摘录真正支撑这句话（审计逐条核对）。
- 二手引用标为二手并指向原始出处，或降级强度。
- 文末"参考文献"只列实际引用的来源，元数据与 `sources` 一致。

## 强度措辞对照

| 证据层级 | 可用措辞 | 禁用措辞 |
|---|---|---|
| `proven` | 研究表明、已证实、一致表明 | — |
| `suggestive` | 初步表明、提示、有迹象 | 证实、证明、一致表明 |
| `contested` | 仍有争议、结论不一致、有相反证据 | 证实、一致表明 |
| `not_reported` | 尚未报告、未见报道 | 任何肯定或否定结论 |

## 三层区分

- **材料事实**：原文直接给出 → 平实陈述 + 引用。
- **合理推断**：由多条证据推出 → 显式标注"综合来看/由此可推断"，并说明推断链条。
- **无法确定**：证据不足 → 写"现有证据不足以判断"，不写结论。

## 反面证据与空白

- 相反结论并列：写明谁 vs 谁、分歧点、可能原因（方法/对象/条件差异）。
- 空白落到具体证据缺口：写"在 X 条件下无直接证据"，不写"尚需进一步研究"。
- 每节可短，但不可缺：证据有限的主题短写并标注证据有限，不为字数硬撑。
