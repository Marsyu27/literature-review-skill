# literature-review：证据可回链的文献综述生成 Skill

> 根目录作品对应 challenge-e97137c9「文献综述生成」。围绕固定研究问题组织文献证据，产出每条论断都可回链到具体文献具体位置的综述草稿与结构化结果。

# literature-review Skill 使用与方法说明

围绕固定研究问题组织文献证据，产出**每条论断都可回链到具体文献具体位置**的综述草稿与结构化结果。适用于文献综述、系统筛选、趋势分析、选题评估与深度研究。

## 这个 Skill 解决什么问题

通用 Agent 写综述常断在四处：筛选无先验标准、主题套通用框架、引用与论断脱节、反面证据被抹平。本 Skill 的对策：

| 常见问题 | 本 Skill 的机制 |
|---|---|
| 筛选标准事后补写 | 纳排标准先于筛选写明，PRISMA 式计数与逐条留证，可复现 |
| 主题套模板 | 先填跨文献比较矩阵，主题自下而上从矩阵聚类，建主题台账 |
| 引用不支撑论断 | 论断（C#）与证据行（E#）双向回链 + 强制引用支持度审计 |
| 强度越级 | 证据四级强度与措辞对照表 + 措辞一致性审计 |
| 出错无法定位 | `result.json` 全字段结构化 + 校验脚本交叉核对 |

## 安装与调用

1. 将本目录作为 Skill 安装到 Agent 的 skills 路径（评测环境为 `/skills/weekly-skill`）。全部资源为纯文本，无第三方依赖；校验脚本只需 Python 3 标准库。
2. Agent 遇到"文献综述/系统筛选/趋势分析/选题评估/深度研究"类任务时触发，按 `SKILL.md` 的 P1–P8 工作流执行。
3. 输入：研究问题 + 文献集（题录和/或 PDF 全文）+ 可选 `output_contract`；评测环境输入位于 `/input/case.json` 与 `/input/task.md`。
4. 输出：`/app/output/`（或用户指定目录）下的 `result.json`（结构化结果）、`review.md`（综述正文）、`evidence_matrix.md`（筛选记录+比较矩阵+证据表）。

## 文件清单

- `SKILL.md`：主提示，含固定工作流与硬规则。
- `references/`：输出字段定义、筛选、证据提取、主题归纳、写作、审计、运行环境七份规程，Agent 按需加载。
- `templates/`：筛选记录、比较矩阵、证据表、综述草稿、审计记录五份模板。
- `scripts/validate_result.py`：结构 + 交叉引用 + 筛选流恒等式 + 论断审计覆盖校验（0 error 方可交付）；具体案例的 `output_contract` 仍须另行逐字段核对。
- `examples/minimal-example.md`：最小调用示例（示意数据，非正式案例结果）。

## 关键设计

- **两遍架构**：生成（P1–P6）与审计（P7）分离。审计含引用支持度、覆盖率交叉检查、强度措辞一致性三项，逐条留痕于 `result.json.audit`。
- **双向回链**：草稿句末标证据行号，文末附论断↔证据对照表，核验者从任一句可跳到证据行再到原文位置。
- **预算安全**：读完输入立即落盘 `result.json` 骨架，逐步就地更新；预算紧张按优先级降级并标 `partial`。

## 限制

- 不负责单篇精读笔记、全文翻译、语言润色、投稿选刊与事实层面学术审查（相邻课题承担）。
- 证据强度判断依赖文献本身的设计与一致性信息；材料未报告时只标 `not_reported`，不外推。
- 语料超过上下文时分批处理，跨批全局综合的质量随批次增多而下降。
