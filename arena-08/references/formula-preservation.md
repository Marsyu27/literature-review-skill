# 公式与特殊字符保真（Formula & Symbol Fidelity）

## 目标

公式、上下标、希腊字母、特殊符号在解析后**不失真**。宁可标注"无法还原"，不可转写成近似字符。

## 规则

1. **保留原文**：每个公式块同时保留 `original`（从 PDF 提取的原始文本/图像）与 `latex`（可读的 LaTeX，若可确定）。
2. **不臆造**：上下标关系、根号范围、分式分子分母、求和上下限若无法从文字层确定 → 标注 `uncertainty`，保留渲染图作为对照。
3. **希腊字母/特殊符号**：`α β γ Δ Σ π σ μ ± × ≤ ≥ →` 等保持原符号，不做 ASCII 化（不把 `α` 写成 `alpha`）。
4. **公式编号**：`(3)`、`Eq. (2)`、`（5）` 保留编号并与公式块绑定。
5. **行内公式**：正文中的行内数学（如 `O(n²)`）保留上下标，不写平 `O(n2)`。

## 特殊字符对照（常见易错）

| 易错 | 保真写法 | 禁止写成 |
|---|---|---|
| 上标 ² | `²` 或 `^2` | `2` |
| 希腊 μ | `μ` | `u` / `mu` |
| 乘号 | `×` | `x` |
| 减号/负号 | `−` / `-` | 保持原文 |
| 千分位/小数点 | 保持原文 | 不改 |

## 不确定处置

- 公式是图片且 OCR 无法确认符号 → 输出渲染图路径，`status` 相应降级，`uncertainties` 记录"公式 (n) 无法可靠还原"。
- 禁止为了"整齐"补全缺项。
