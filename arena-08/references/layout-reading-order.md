# 多栏阅读顺序与页眉页脚判定（Layout & Reading Order）

> 机械实现：`scripts/parse_pdf.py` 已按本文件规则产出初排（词 xMin 直方图双峰 + 栏间谷底判双栏、左栏→右栏阅读顺序、≥50% 页重复行剔除页眉页脚）。本文件是 LLM 在 `blocks.json` 上做**语义修正**时的判定依据；修正须写依据进 `uncertainties`。

## 判栏

1. 用 `pdftoppm -png -r 150` 渲染页面，或 `pdftotext -bbox-layout` 拿字符坐标。
2. 统计每页文本块的 x 坐标分布：
   - 若明显聚成两组（如左块 x<300pt、右块 x>300pt）→ 双栏。
   - 三组及以上 → 多栏。
   - 单组连续 → 单栏。
3. 栏边界取相邻两组 x 坐标的**分界点**（两组坐标的中值）。

## 阅读顺序（双栏通用）

默认顺序：**左栏自上而下 → 右栏自上而下**，但以下元素除外（跨栏元素优先）：

- 跨栏大标题、作者/单位块、通栏摘要、通栏图表 → 视为"跨栏块"，排在两栏正文之前（按其纵向位置）。
- 每页的栏内顺序按 y 坐标自上而下、同 y 按 x 从左到右。
- 跨页段落：上一页右栏末尾未完的句子，接到下一页对应栏的句首；不得重复该句。

## 页眉页脚 / 边注 / 水印

识别并**排除**出正文（单独标记，不删除信息）：

- 页眉：页面顶部固定位置重复出现的短文本（如期刊名、卷期、DOI、页眉标题）。
- 页脚：底部固定位置的页码、版权、投稿日期。
- 边注/水印：固定角标或居中半透明文字（如 "Accepted Manuscript"、"arXiv:..."）。

判定法：同一文本在同一 y 区间、多页重复出现 → 页眉/页脚；标记 `type=header/footer`，正文输出时置于独立字段，不混入段落流。

## 不确定时的处置

- 若两栏边界模糊（如公式横跨两栏、表格跨栏），**取最可能顺序**，并在 `uncertainties` 记录："页 N 栏边界不确定，已按 X 顺序，依据 Y"。
- 禁止为了"整齐"而丢弃文本或自行拼接出原文不存在的句子。
