# 表格结构重建规则（Table Structure）

## 定位

- 依据：框线、题注（`Table 1` / `表 1` / `Tab. 1`）、纵向分隔线。
- 题注在上方还是下方以原论文为准，**保留原位置与编号**。

## 单元格归属判定

1. 用渲染图 + 坐标定位列边界（竖线/空白间隙）与行边界（横线/基线）。
2. 合并单元格：同一单元格内容跨越多个列/行位置时，判为 `rowspan`/`colspan`，用 HTML 表达最准确。
3. 多层表头：表头行分层的，保留层级，不压平成单行。
4. 跨页续表：下一页出现 `Table N (continued)` 或重复表头时，合并为同一张表，标注"续表，起始页 X"。

## 输出格式

- 简单表格 → Markdown：
  ```markdown
  | 参数 | 数值 | 单位 |
  |---|---:|---|
  | α | 0.32 | — |
  ```
- 含合并单元格/多层表头 → HTML（`rowspan`/`colspan`），并附题注。
- 每个表格附带：`id`（原编号）、`page`、`caption`、`source_bbox`（可选）。

## 图片型表格

- 表格区域无文字层（是图片）→ 标注 `type=image_table`，尝试 OCR；OCR 低置信度则如实标注 `uncertainty`，**不臆造数字**。

## 数值纪律

表格内的数字、单位、符号、上下标**逐字保留**；`<`、`±`、`×10⁻³` 等不得改写为近似。
